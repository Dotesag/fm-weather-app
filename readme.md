### The challenge

This is a simple weather app which shows current, daily and hourly forecast. It uses Open-Meteo API for geocoding and making forecasts and also ipwho.is for geocoding by IP address of user.

### Development stack

- **Next.JS** - react framework
- **Tailwind CSS** - utility-first CSS framework
- **TypeScript** - typed JavaScript
- **React** - library for creating user-interfaces

### Quick start

1. Repository cloning

```bash
git clone https://github.com/Dotesag/fm-weather-app
cd fm-weather-app
```

2. Installing NPM dependencies

```bash
npm install
```

3. Launching in dev mode

```bash
npm run dev
```

The application will be available on the **http://localhost:3000** address.
